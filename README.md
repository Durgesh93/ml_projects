# ml_projects

Collection of older machine-learning projects, each on its own branch.
The `main` branch is intentionally empty.

| Branch                   | Project                                                                 |
|--------------------------|-------------------------------------------------------------------------|
| `DETR`                   | Detection Transformer on Multi-MNIST (unofficial)                       |
| `Orca_al`                | Orca detection (active learning notebooks)                              |
| `orca_detect`            | Orca detection (formerly `Devesh42/orca_detect`)                        |
| `Acne_detection`         | Acne severity prediction using OpenCV                                   |
| `Image_Segmentation`     | Image segmentation with K-means, Fuzzy C-means and Mean-shift           |
| `Forestfire`             | Forest-fire prediction                                                  |
| `BuyAffinity`            | Purchase-tendency prediction for e-commerce customers                   |
| `Market_basket_analysis` | Market basket analysis with the Apriori algorithm                       |
| `POS_Tagging`            | Part-of-speech tagging with a GRU                                       |
| `Collocation`            | Finding collocations in Moby Dick                                       |
| `fish`                   | Fish classification: ensemble and pond evaluation (formerly `fish` repo) |

```bash
git clone -b DETR https://github.com/Durgesh93/ml_projects
```
